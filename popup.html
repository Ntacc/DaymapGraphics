General settings

Opacity

The opacity of the cards.

Blur

How much the cards blur the background when they are translucent or transparent. ALSO. IT MAKES DAYMAP REALLY LAGGY. I DON'T RECOMMEND YOU ENABLE IT. EVEN THOUGH IT LOOKS REALLY COOL.

Original layout

Revert the layout of Daymap pages to the layout from before the 30th of May 2022.

Background CSS property

Out of all the features, this is the hardest to use. This should take the form of a CSS background property. You can use colours, linear gradients, and more. I personally like linear-gradient(to bottom right, #ABCDEF, turquoise, plum). However, you can also use images, including animated ones. The format for this should resemble url('https://i.ytimg.com/vi/dQw4w9WgXcQ/hqdefault.jpg'). You may also wish to resize and reposition an image, so use the format url('https://cdn.esawebb.org/archives/images/screen/carinanebula3.jpg') 0 0 / cover.

Rainbow speed

How fast the rainbows change colour and moves around (see below: effects menu).

Profile picture URL

In feed view, there's a profile picture thingy that doesn't seem to get used. So if you want to change it, paste in a link to an image.

The effects menu

Starry background

Adds stars to the background.

Rainbow indicators

One of the first features of Daymap Graphics was being able to click on an indicator to change its colour. An easter egg was typing in "RAINBOW" as the colour would make it continuously change colour. Now, you can automate it.

Rainbow background

An animated rainbow background. Probably one of my favourite features so far!

Bubbles

Slowly rising bubbles.

Colour generators

Each colour generator produces different styles:

  • Classic (based on a program from @WeatherWonders on Khan Academy) produces more saturated colours.
  • Pastels (by me!) generates sets of pastel colours based around themes (so you'll rarely see clashy colours).
  • Uniform colours just means there's no pattern to how it's generated.

I hope this guide helped!

Changelog

8.1.1

Improved bubble performance by using 3D transformations and opacity in @keyframes instead of constantly modifying top, width, height, and background. Fixed an issue where closing a page caused the background script to break. Effects menu now always chooses the default colour generator when switching effects. transition: all on script injection instead on settings change.

8.1.0

Used messages to sync changes live more smoothly than detecting storage changes and added a background script for message passing. Added an effects menu, alongside the background rainbow and bubbles effects. Fixed an oversight where the custom profile picture was not added to the menu in the new layout. Added a super awesome pastel colour generator.

8.0.1

Fixed the rainbow still keeping the same colour even when turned off and only showing one colour, added custom profile picture to the header in the original layout, modified the setting updating code to prepare for release on Firefox-based browsers, original layout now changes the page live, added transitions to card elements to smooth out changes in sliders.

8.0.0

Revamped popup.html, made stars a feature (previously it was only an easter egg), tidied and optimised the code, moved most long strings to a new resources.json, changed popup.html to avoid exceeding the MAX_WRITE_OPERATIONS_PER_MINUTE quota (trying to avoid using workers), and changed the content script to display these changes live. A bit of a change in direction, may add more animations later.
