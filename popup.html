The Handbook

Opacity

This slider allows you to control the opacity of the foreground of Daymap. Note that this does not change the opacity of the text.

Blur

This changes how much the foreground "cards" blur the background when they are translucent or transparent. This is measured in pixels. ALSO. IT MAKES DAYMAP REALLY LAGGY. I DON'T RECOMMEND YOU ENABLE IT. EVEN THOUGH IT LOOKS REALLY COOL.

Auto indicator rainbow

One of the first features of Daymap Graphics was being able to click on an indicator to change its colour. An easter egg was typing in "RAINBOW" as the colour would make it continuously change colour. Now, you can automate that process by checking this box.

Original layout

Revert the layout of Daymap pages to the layout from before the 30th of May 2022. (Personally, I recommend enabling this, as it fixes some of the main complaints with the new layout).

Starry background

Adds stars to the background. That's pretty much it. It's probably best to pair this with a darker background, but it's your Daymap, so the sky's the limit. Or the stars.

Background CSS property

Out of all the features, this is the hardest to use. This should take the form of a CSS background property. You can use colours, linear gradients, and more. I personally like linear-gradient(to bottom right, #ABCDEF, turquoise, plum). However, you can also use images, including animated ones. The format for this should resemble url('https://i.ytimg.com/vi/dQw4w9WgXcQ/hqdefault.jpg'). You may also wish to resize and reposition an image, so use the format url('https://cdn.esawebb.org/archives/images/screen/carinanebula3.jpg') 0 0 / cover.

Rainbow speed

Pretty self explanatory. If indicator rainbow is on, this just changes how fast the rainbow changes colour and moves around.

Profile picture URL

In feed view, there's a profile picture thingy that doesn't seem to get used. So if you want to change it, paste in a link to an image.

I hope this guide helped!
